# Anthony Martinez — Portfolio

Horizontal-scroll portfolio built from scratch with vanilla HTML, CSS and JavaScript — no frameworks, no build step.

**Live:** https://martinez-devs1412120.github.io/portfolio/

## Highlights

- Panel-by-panel horizontal navigation (mouse wheel, touch swipe, keyboard)
- Accordion project gallery with blur-reveal screenshots
- Scroll-driven photo expansion with masked blur layers
- Accessible: keyboard navigation, `prefers-reduced-motion` support, WCAG-conscious contrast

## Stack

HTML · CSS · JavaScript
